Force Graph

Um grafo de dependências que se organiza sozinho. Arraste os nós, passe o mouse para ver as ligações de cada um.

Uma simulação por passos, como a do d3-force: cada nó repele todos os outros (lei do inverso do quadrado), cada aresta é uma mola com comprimento de repouso, e uma gravidade fraca puxa tudo ao centro. A velocidade é integrada com amortecimento, e uma "energia" alpha esfria a cada passo até o grafo parar — arrastar um nó reaquece. A repulsão é O(n²), suficiente até algumas centenas de nós; acima disso entraria uma quadtree (Barnes–Hut).
