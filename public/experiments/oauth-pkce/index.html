OAuth PKCE

O fluxo authorization code + PKCE passo a passo, com WebCrypto de verdade. É o que impede que um código interceptado vire token.

O code_verifier vem de crypto.getRandomValues e o desafio de crypto.subtle.digest('SHA-256', …), ambos nativos do browser. Como só o hash viaja na primeira ida, quem interceptar o code no redirect não consegue montar o /token — é isso que o modo "código roubado" mostra. Sem PKCE, esse roubo bastava.
