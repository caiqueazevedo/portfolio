SVG Sparklines

Quatro mini-gráficos em SVG puro: linha, área, barras e degrau. Passe o mouse pra ver o valor.

Cada gráfico é um <svg> com viewBox fixo: os pontos são mapeados pra 0–100 e o CSS estica. A linha suave é um <path> com curvas Bézier cúbicas calculadas dos vizinhos; a área é a mesma linha fechada até a base. A entrada anima stroke-dashoffset. O tooltip acha o ponto mais próximo do mouse pela coordenada X.
