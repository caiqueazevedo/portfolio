Variable Type

Uma única fonte variável; cada letra ganha peso e largura conforme o cursor se aproxima. Sem trocar de arquivo, sem imagem.

O Roboto Flex expõe os eixos wght (100–1000) e wdth (25–151) num só arquivo. Cada letra é um span com font-variation-settings alimentado por variáveis CSS. A distância do ponteiro ao centro da letra passa por uma curva cosseno até o raio escolhido; o valor aplicado persegue o alvo com uma interpolação por quadro, daí a inércia. As posições dos centros são medidas de novo a cada quadro porque a própria largura muda.
