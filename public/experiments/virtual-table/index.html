Cem mil linhas rolando liso. Só as visíveis existem no DOM; o resto é um espaçador com a altura certa.

O scroller tem um filho com height = linhas × altura, então a barra de rolagem é honesta. A cada scroll, calcula-se first = floor(scrollTop / altura) e renderizam-se só as ~20 linhas visíveis mais uma folga, deslocadas com transform: translateY(first × altura). Ordenar e filtrar mexem num índice, não no DOM.
