Knockout Marquee

Um texto gigante corre em loop e mostra a foto por dentro das letras. A foto fica parada; só a máscara anda.

A <image> recebe mask="url(#knock)"; a máscara é um <text> com o texto repetido. A Web Animations API (element.animate) desloca o texto exatamente uma repetição por ciclo, então o loop não pula. Com prefers-reduced-motion o texto fica parado.
