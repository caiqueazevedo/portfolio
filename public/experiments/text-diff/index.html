Text Diff

O diff do Git, no browser: linhas adicionadas e removidas e, dentro delas, as palavras que mudaram.

O algoritmo é o de Myers (1986), o mesmo do git diff: procura o caminho com menos edições numa grade de "antes × depois", avançando por diagonais — que são as linhas iguais — e guarda cada fronteira para reconstruir o caminho de trás para frente. Roda duas vezes: nas linhas e, para cada bloco de linhas removidas seguido de adicionadas, nas palavras de cada par.
